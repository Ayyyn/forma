# Optical search-program feasibility probe — 2026-10-30

Development probe, not a held-out claim of general AI superiority. Fixed eight-layer TiO2/SiO2 ordering from the conventional quarter-wave grid; search thicknesses only. It cannot discover a new material or an arbitrary topology. No fabrication experiments.

Physics: measured dispersive n/k inputs, coherent planar films, air to semi-infinite silica. Objective is `violation + .01*(2-T-R)`; T/R are the minimum uniform-wavelength band integrals over 0/30 degrees, s/p and five fixed nominal/±3 nm perturbations. T target .85 at 450–650 nm; R target .8 at 900–1100 nm. Nominal thickness 23–347 nm keeps perturbed layers within 20–350 nm; total perturbed thickness must stay <=3000 nm. Forty-one quadrature points per band during search; 401/801 point audits afterwards. Sampled tolerances are not a worst-case certificate.

Three sequential development rounds, 256 oracle calls per round per method, strict cap including invalid proposals and finite differences. Each method starts round 1 at the same conventional recipe and later rounds at its own best. Compare Meta-authored numerical search programs with L-BFGS-B finite differences and differential evolution. Both numerical controls receive three rounds too; do not compare best-of-three Meta with a single baseline run. Every objective call counts; each valid query invokes 20 optical spectra (five perturbations, two angles, two polarizations). Repeated recipes count again. Offline audits are separate. No equal wall time or model-compute claim.

Muse Wonder high reasoning writes a complete numerical program through a tool. Its returned code is never executed as Python: an AST interpreter permits finite arrays and bounded arithmetic/for loops, exposes only a scalar oracle, and excludes imports, attributes and file/network operations. The host keeps the best verified score, not any self-reported model score. Original received code remains unchanged; rejected programs/errors remain recorded. Per-round parser/runtime errors are feedback, not silently repaired by a human. At most three actual model requests in this probe, with a $10 usage-estimate ceiling (well within the expanded research authorization); transport failure stops dispatch. Provider billing is not verified by usage estimates.

Meta sees task/formulation, its prior code and its own query evidence. It does not see the separate non-AI refined feasible witness, baseline traces or outcome scores before completing its round. Prompts necessarily identify a known development problem; no novelty or unseen-task advantage claim. Numerical methods are conventional strong local/global controls, not certified global optima.

Interpretation: a valid program plus improving checked designs demonstrates an executable AI capability. An advantage requires beating both complete numerical budgets and then repeating on unseen tasks/seeds, charging all outer program-selection/development queries. No discovery/prototype savings conclusion from this probe. Prior art: Yin et al., *Optimizing Photonic Structures with Large Language Model Driven Algorithm Discovery*, https://arxiv.org/abs/2503.19742 . LLM-generated photonic optimization algorithms are established.
