# Nonlinear robustness repair — prospective development protocol

Frozen before new searches/calls. Earlier nonlinear-discovery-v1 remains unchanged.
The earlier high-bias candidate fails a new 5 Nmm clamp-torque screen; removing
equal common torsion offsets is an analytical repair shared with both controllers.
The corrected audit then finds shallow sampled escape paths and only 2/8 local
tolerance continuations pass. This is a new task, not a retroactive re-score.

Both controllers receive three identical earlier designs and have 32 charged
candidate queries including these seeds, 16 stationary root starts per setting,
and up to 12 index-one saddles per setting followed in both unstable directions.
The same state-search/summary evaluator is used. Numerical work varies with
saddle counts, root iterations, convergence and line searches; count this work
and elapsed time, and make no equal-CPU/FLOP or efficiency claim from query caps.

Grammar and published cell energy are unchanged. Novelty of Kresling inverse
design, prestress, multistability, origami memory and deterministic optimization
is explicitly disclaimed. The task remains synthetic and ideal-guide constrained.
All earlier physical exclusions apply: no lateral/contact/dynamics/material
failure/finite thickness/fatigue/hinge hardware or fabrication calibration.

Nominal screen: coexisting target/opposite local minima at both settings;
target polarization >=.35 at A, <=-.35 at B; found-state bias >=.5 mJ;
selected normalized Hessian eigenvalues >=.0002; |axial holding force|<=1.5 N;
|holding torque|<=5 Nmm. Both selected modes need a constructed path to another
minimum. Reject any identified sampled path height below .5 mJ. Those sampled
energies are neither certified continuous bounds nor minimum-energy barriers;
passing this screen does not establish retention. Missing paths fail the screen
as unresolved, not as proof the mechanism is impossible.

Rank nominal passers by smaller A/B energy bias; otherwise by sum of normalized
violations. Numerical control: 12 paired-torsion stiffness continuation designs,
then seeded Sobol variation spanning full permitted preload ranges and geometry,
chirality and added spring spans/types. This controller was written before the
new Meta responses. It is a serious small-budget heuristic, not a global optimum.
Meta receives the same seeds and all equations/grammar/failures in public tool
context, evaluates via tools, inspects cached results, and can finish early.
At most 8 actual Muse Wonder calls, high reasoning, 12,288 output tokens/call,
conservative estimated $15 phase cap. Record provider IDs, HTTP results and token
usage. Never count offline numerical analysis as Meta calls or infer billing.

Top three nominal-ranked candidates per policy receive 128 starts/setting,
independent vertex energy and finite-difference Hessian checks, and eight seeded
local tolerance continuations of the four selected modes. h0 varies ±1%, theta0
±.25 degrees, k ±5%, axial offsets ±.25 mm, torsional offsets ±.01 rad. Require
all eight samples to preserve local modes, polarization and force/torque/Hessian
guards for final acceptance. Uncertainty can extend beyond nominal proposal
bounds; these bounds are a search grammar, not a constitutive validity theorem.
This is local persistence at sampled perturbations, not global robustness or
fabricated-part validation. No test-set population, statistical AI superiority,
new-to-science structure or avoided-prototype claim is justified by this run.

All sources/protocol/input seeds are hashed and copied before execution. Raw
results are not overwritten. Follow-up diagnostics must use new filenames and
be identified as post-hoc.
