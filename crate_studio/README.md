# Forma Studio

See the [project README](../README.md) for setup, features and limitations.

The application runs on localhost. Set MODEL_API_KEY server-side for Muse Wonder proposals; credentials are never part of public source. Parametric edits and native geometry checks operate on shared revisioned design state. Motion checks sample prescribed kinematics and do not replace physical mechanism testing.

The independent analytic geometry/reference helpers retained alongside Studio have their own narrow scope; their inclusion does not establish general physics capability.
