# 0006 — Select execution-backed bug reproduction; hold the main build

October 28, 2026. Research candidate selected; overall capability gate not passed.

Compared CAD change automation, assembly-error detection, paper reproduction, accessibility/web-testing repair and bug reproduction after the Kresling Meta-value no-go. Selected a bounded report-to-executable-regression workflow because Meta can interpret informal intended behavior while independent execution supplies the verdict. Public real bugs and a fresh local defect can be tested without a hardware dependency.

This is established work: SWT-Bench, TEX, automated property testing and commercial bug-report/test tools provide substantial prior art. We claim a new scoped implementation/evidence workflow, not invention of test generation, red/green proof, mutation testing or coding agents.

Preserved v1 after an output-envelope integration failure: Meta 2/16 verified real-issue suites. Separately froze v2 with strict native/JSON/observed-atem decoding and a header-value assertion. v2 gets 13/16 verified suites across 7/8 real issues, versus 6/16 across 3/8 for limited literal rules; structured missing-information controls 3/4 versus 4/4. The frozen overall gate **fails** on clarification completeness. This development retest is not a new held-out benchmark or evidence of superiority over existing coding agents.

A separate actual Meta call authored regression/control inputs for a freshly reproduced parser defect in our code. The tests fail on the original, pass on a separately written correction and reject an overbroad all-reject mutant. Meta authored test data, not the bug discovery or correction. One assisted example supports useful test design; it does not erase the failed overall gate.

Decision: retain this candidate and its runnable research proof; hold the main product/UI build. A reviewed small-Python/API scope is feasible. Before committing the remaining hackathon time, require a fresh real developer workflow, an ordinary coding-agent comparator, structured clarification reliability and a verified execution environment for that scope. Broad repository execution, autonomous approval, workflow time savings and commercial novelty remain unverified.

All 65 tests pass. This round used 43 actual requests, about $0.294 estimated reported usage. Original/fixed source fixtures, both protocol matrices, diagnostics, hashes and replay scripts remain separate. See `docs/PIVOT_BUG_REPROOF.md` for evidence, assumptions, attribution and commands.
