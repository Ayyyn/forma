# 0003 — Pivot the next demo to material revisions for static display fixtures

Date: October 27, 2026. Status: selected direction; production implementation not yet started.

The user requested stronger directions with practical usefulness, meaningful Meta use and defensible novelty, and supplied a designer's workflow: SolidWorks static stalls/crates and customer material substitutions affecting thickness, geometry, renders and vendor drawings. Physical origami verification is deferred.

Select a material-revision desk for one bounded static panel-display family. Meta interprets informal changes and identifies missing decisions. Deterministic tools compute geometry, dimensional implications, fit/tolerance bounds and consistent artifacts. Explicit preserved requirements, source references, human-reviewed edits and revision identity connect the canvas stages.

This is a scoped workflow contribution, not the first AI CAD, automatic drawing update, thickness-aware generator or material-selection method. SolidWorks/DriveWorks, Zoo, DraftGuard and LaserSVG establish substantial prior art. The actual novelty/value must come from the implemented interaction and evaluated handling of intent, conflicts and vendor handoffs.

The first prototype does not promise native SolidWorks round trips, arbitrary image-to-CAD reconstruction, DWG export, FEA, structural material equivalence, automatic cost reduction or manufacturing approval. Render/model/drawings derive from one typed project representation. The original origami code and benchmark evidence are retained.

One actual Meta request on five synthetic revision cases confirms a feasible typed-proposal path, but manual review found a current-dimension versus minimum-requirement ambiguity. Semantic preservation and supplied tolerance checks must gate the new implementation. Before major UI investment, compare at least one relevant workflow with the designer's existing method; customer value remains unvalidated.
